# Proyecto TFC UFV

Proyecto fullstack con React (frontend), FastAPI (backend) y PostgreSQL (base de datos), todo gestionado con Docker Compose.

## Estructura
- backend: FastAPI + Python
- frontend: React
- db: PostgreSQL

## Cómo levantar el proyecto
1. Instala Docker y Docker Compose.
2. Ejecuta:
   ```
   docker-compose up --build
   ```
3. Accede a:
   - Frontend: http://localhost:3000
   - Backend: http://localhost:8000
   - Base de datos: localhost:5432
